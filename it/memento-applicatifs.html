git — initialiser & configurer

git — suivre les changements

git statusAfficher le statut du dépôt
git add fichierAjouter un fichier au staging
git add .Ajouter tous les changements
git commit -m "message"Valider avec un message
git commit -am "message"Valider les fichiers suivis, sans add

git — synchroniser

git pushEnvoyer les commits vers le distant
git push -u origin branchEnvoyer et suivre une branche
git push origin --delete branchSupprimer une branche distante
git pullRécupérer et fusionner les changements distants
git fetchRécupérer sans fusionner

git — branches

git branchLister les branches locales
git branch -aLister toutes les branches
git branch nomCréer une nouvelle branche
git checkout branchChanger de branche
git checkout -b branchCréer et changer de branche
git merge branchFusionner une branche dans la courante

git — historique & divers

git log --graph --allHistorique visuel avec les branches
git diff · git diff --cachedDifférences non indexées / indexées
git reset fichierRetirer un fichier du staging
git reset --hardAnnuler tous les changements
git revert commitCréer un commit qui annule un autre
git tag v1.0Créer un tag / une release
git stash · git stash popMettre de côté / récupérer les changements

git — avancé

git remote add origin urlLier le dépôt à une origine distante

git cherry-pick commitAppliquer un commit précis sur la branche

GitHub Actions & gh CLIworkflows · jobs · étapes · pull requests

GitHub Actions — structure

.github/workflows/ci.ymlEmplacement des workflows dans le dépôt
name: CINom affiché du workflow
on: [push, pull_request]Déclencheurs du workflow
on: push: branches: [main]Limiter à une branche
on: schedule: - cron: '0 2 * * *'Exécution planifiée
on: workflow_dispatchDéclenchement manuel depuis l'interface
jobs:Bloc contenant les tâches
runs-on: ubuntu-latestMachine d'exécution (windows/macos-latest)
steps:Liste ordonnée des étapes du job
needs: buildAttendre qu'un autre job réussisse
strategy: matrix: node: [18, 20]Tester plusieurs versions en parallèle

GitHub Actions — étapes courantes

uses: actions/checkout@v4Récupérer le code du dépôt
uses: actions/setup-node@v4Installer Node.js
uses: actions/setup-python@v5Installer Python
run: npm ci && npm testExécuter des commandes shell
run: |Bloc multi-lignes de commandes
with: node-version: 20Paramètres passés à une action
env: NODE_ENV: productionVariables d'environnement
if: github.ref == 'refs/heads/main'Étape conditionnelle
uses: actions/upload-artifact@v4Publier un artefact de build
uses: actions/cache@v4Mettre en cache les dépendances
${{ secrets.MON_TOKEN }}Utiliser un secret du dépôt
${{ github.sha }} · github.actorVariables de contexte

Bases de donnéesMySQL · MariaDB · SQLite · SQL

MySQL / MariaDB — connexion

mysql -u user -pSe connecter (mot de passe demandé)
mysql -u user -p baseSe connecter directement à une base
mysql -h serveur -P 3306 -u user -pConnexion à un serveur distant
SHOW DATABASES;Lister les bases
USE base;Sélectionner une base
SHOW TABLES;Lister les tables
DESCRIBE table; · SHOW COLUMNS FROM t;Structure d'une table
SHOW CREATE TABLE t;Script de création de la table
SHOW PROCESSLIST;Requêtes en cours d'exécution
STATUS;Infos sur la connexion et le serveur
exit · \qQuitter le client

MySQL / MariaDB — administration

CREATE DATABASE base CHARACTER SET utf8mb4;Créer une base
DROP DATABASE base;Supprimer une base
CREATE USER 'u'@'localhost' IDENTIFIED BY 'mdp';Créer un utilisateur
GRANT ALL ON base.* TO 'u'@'localhost';Donner les droits sur une base
GRANT SELECT, INSERT ON base.* TO 'u'@'%';Droits limités, depuis tout hôte
REVOKE ALL ON base.* FROM 'u'@'localhost';Retirer les droits
FLUSH PRIVILEGES;Recharger la table des droits
SHOW GRANTS FOR 'u'@'localhost';Voir les droits d'un utilisateur
ALTER USER 'u'@'localhost' IDENTIFIED BY 'nv';Changer un mot de passe
DROP USER 'u'@'localhost';Supprimer un utilisateur
systemctl status mariadb · mysqlÉtat du service

MySQL / MariaDB — sauvegarde

mysqldump -u user -p base > sauv.sqlSauvegarder une base
mysqldump -u user -p --all-databases > all.sqlSauvegarder tout le serveur
mysqldump -u user -p base table > t.sqlSauvegarder une seule table
mysqldump --no-data base > schema.sqlStructure seule, sans les données
mysql -u user -p base < sauv.sqlRestaurer une sauvegarde
mysqldump ... | gzip > sauv.sql.gzSauvegarde compressée
gunzip < sauv.sql.gz | mysql -u user -p baseRestaurer depuis une archive
SOURCE /chemin/fichier.sql;Exécuter un script depuis le client
mysqlcheck -u user -p --auto-repair baseVérifier et réparer les tables

SQLite

sqlite3 base.dbOuvrir (ou créer) une base
.tablesLister les tables
.schema tableStructure d'une table
.headers on · .mode columnAffichage lisible des résultats
.mode csv · .output f.csvExporter les résultats en CSV
.import f.csv tableImporter un CSV dans une table
.dump > sauvegarde.sqlExporter toute la base en SQL
sqlite3 base.db < sauvegarde.sqlRestaurer une base
.backup sauv.dbSauvegarde binaire à chaud
.read script.sqlExécuter un script SQL
.databases · .indexesBases attachées · index
.quitQuitter
sqlite3 base.db "SELECT * FROM t;"Requête directe depuis le shell

SQL — requêtes de base

SELECT * FROM table LIMIT 10;Voir les premières lignes
SELECT col1, col2 FROM t WHERE cond;Sélection filtrée
WHERE col LIKE '%motif%'Filtrer par motif
ORDER BY col DESCTrier les résultats
INSERT INTO t (a,b) VALUES (1,'x');Insérer une ligne
UPDATE t SET a=1 WHERE id=2;Modifier des lignes
DELETE FROM t WHERE id=2;Supprimer des lignes
SELECT count(*) FROM t;Compter les lignes
SELECT a, count(*) FROM t GROUP BY a;Agréger par valeur
SELECT * FROM a JOIN b ON a.id=b.a_id;Jointure entre deux tables
LEFT JOIN · INNER JOINTypes de jointures
CREATE INDEX idx ON t(col);Créer un index
EXPLAIN SELECT ...;Analyser le plan d'exécution
BEGIN; · COMMIT; · ROLLBACK;Transactions

API & JSONcurl · jq · requêtes HTTP

curl — requêtes HTTP

curl urlRequête GET simple
curl -i urlAfficher aussi les en-têtes de réponse
curl -I urlEn-têtes seulement (HEAD)
curl -L urlSuivre les redirections
curl -o fichier urlEnregistrer dans un fichier
curl -X POST urlChoisir la méthode HTTP
curl -H "Content-Type: application/json"Ajouter un en-tête

curl -s url | jq .Sortie silencieuse, formatée par jq

Codes HTTP à connaître

200 OK · 201 CreatedSuccès · ressource créée
204 No ContentSuccès, aucun corps renvoyé
301 · 302Redirection permanente · temporaire
400 Bad RequestRequête mal formée
401 · 403Non authentifié · authentifié mais interdit
404 Not FoundRessource inexistante
409 ConflictConflit avec l'état actuel
422Données valides en forme mais refusées
429 Too Many RequestsQuota / limitation dépassée
500 · 502 · 503Erreur serveur · passerelle · indisponible
